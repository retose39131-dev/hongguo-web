# 红果免费短剧 · Web 版（真实内容 + 真实播放）

**仅供学习交流使用**。基于公开接口的短剧网页实现。
**无需登录、无广告、无 VIP 限制、全剧集免费**。

内容源与播放解析来自开源项目 [N3urda/hongguoTV](https://github.com/N3urda/hongguoTV)（GPL-3.0），
本仓库在其之上增加了浏览器可播放的转码管线与前端。

## 快速启动

```bash
# 1) 启动内容桥接服务（真实红果内容：首页/搜索/详情）
cd /root/test/.cache/hongguoTV && node server/index.mjs --lan

# 2) 启动网页版（另一个终端）
cd /root/test/webapp && node server.js
# 打开 http://127.0.0.1:8899
```

或使用一键脚本：`bash /root/test/webapp/start.sh`

## 播放链路（三种模式，自动选择）

红果原片为 **H.265 (bytevc1) + CENC AES-CTR 加密**。**raw 模式采用流式解密**：浏览器 Range 请求 → bridge 按 1MB 段实时解密回传，**不落盘、不转码、首帧秒开**。

| 模式 | 适用 | 处理 | 首帧速度 |
|---|---|---|---|
| `raw` 原画流式 | **支持 HEVC 的浏览器**（Windows/Mac Chrome/Edge、Safari、部分 Android） | 代理 bridge `/api/episodes/:id/stream`，Range 按需解密（同 hongguoTV 方案） | **~0.5 秒** |
| `fast` 官网直连 | 所有浏览器（不支持 HEVC 时默认） | 官网明文 H.264 `360p.mp4` 直接代理 | **~0.5 秒** |
| `h264` 转码 | 不支持 HEVC 的浏览器选高清时 | 解密 + ffmpeg 转码并缓存 | 10~30 秒 |

默认策略：支持 HEVC → **1080P 原画（raw 流式）**；否则 → **官网 360P（fast）**。
播放页「更多设置」可手动切换。

## 播放页交互（对齐原 App）

- **上下滑动切换集数**（全屏竖屏信息流，scroll-snap 吸附，同一时间只播放一个视频）
- **中央播放/暂停按钮**（播放时隐藏，暂停时显示 ▶）
- **可拖动进度条**（拖动时预览时间；松手 seek 并静音过渡，避免旧音频残留）
- 右侧互动栏：点赞（双击视频也可点赞）/ 评论 / 收藏 / 分享
- 自动连播：本集播完自动滑到下一集
- 选集面板：任意集数直达；更多设置：倍速/清晰度/弹幕/自动连播
- 进入页面自动从上次观看的集数开始（URL 随滑动实时更新）
